# bil

The Python interface of the Blazing Imaging Library, which reads imaging sensor data and its metadata from any format and delivers a processable subset as native Fragments or 2D float32 Slices.

**This is an early preview with no reading interface yet.** It holds the project's name while the library is built over the Rust core. See https://github.com/code-moth/BlazingImagingLibrary for the specification and progress.
